# Website Young Go – Trekking & Camping

Website giới thiệu và nhận đặt tour của Công ty TNHH Du lịch Young Go (đồ án môn học).

- `index.html`: trang chủ (4 tour: Núi Chúa, Ea Snô, IDEAL Phước Bình – Cát Tiên, Tà Năng sắp ra mắt)
- `nui-chua.html`: trang chi tiết tour Núi Chúa 2N2Đ
- `images/`: hình ảnh

Các chỗ trong ngoặc vuông như [SỐ HOTLINE], [SỐ GIẤY PHÉP] cần điền thông tin thật trước khi công bố.
